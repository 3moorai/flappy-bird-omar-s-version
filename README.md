# Flappy Bird 🌋❄️ • Magma & Frost Edition

لعبة **Flappy Bird** أيقونية بتصميم فائق التطور يجمع بين **عالم الحمم البركانية (Magma Biome 🌋)** و**عالم الجليد القطبي (Glacial Frost Biome ❄️)**، مع دعم الشاشة الكاملة ومؤثرات صوتية وإشعاعية تفاعلية!

---

## 🎮 المميزات الرئيسية (Key Features)

- **❄️ الوضع الجليدي (Glacial Frost Mode)**: طائر فلابي بيرد الأزرق المتجمد، أوردة نيون ثلجية، أمواج الشفق القطبي (Aurora Borealis)، وتساقط بلورات الثلج الألماسية.
- **🌋 الوضع البركاني (Volcanic Magma Mode)**: طائر فلابي بيرد الأصفر، أوردة الحمم المنصهرة، وتطاير شرارات الجمر الصاعد.
- **🔥 طور التحطيم الخارق (Super Phoenix Overdrive)**: عند تحقيق 10 كومبو متتالي، يتحول الطائر إلى طائر خارق لا يُقهر يحطم أي عمود يعترض طريقه!
- **🖥️ شاشة كاملة حقيقية (Full-Window & Fullscreen ⛶)**: اللعبة تملأ كامل نافذة المتصفح بدقة عالية وتتكيف مع أي شاشة كمبيوتر أو هاتف.
- **🎵 مؤثرات صوتية إجرائية (Procedural Web Audio API)**: لا تحتاج إلى تحميل أي ملفات صوتية خارجية، جميع المؤثرات تُولد في الوقت الحقيقي داخل المتصفح.

---

## 🕹️ طريقة التحكم (Controls)

| المفتاح | الوظيفة |
| :---: | :--- |
| **`Space` / `↑` / `W` أو النقر** | رفرفة الأجنحة والتحليق للأعلى |
| **`T`** | التبديل الفوري بين عالم الجليد ❄️ وعالم الحمم 🌋 |
| **`F`** | تفعيل / إلغاء ملء الشاشة بالكامل (Fullscreen ⛶) |
| **`M`** | كتم / تشغيل المؤثرات الصوتية |

---

## 🚀 التشغيل المباشر
افتح ملف `index.html` في أي متصفح حديث (Chrome, Edge, Firefox, Safari) لتشغيل اللعبة فوراً بدون أي تثبيت أو خوادم خارجية.
